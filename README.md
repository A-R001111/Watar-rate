## افزونه Water Bill Dashboard

این افزونه یک داشبورد سمت کاربر برای مدیریت قبض‌های آب است که با شورت‌کد `[water_bill_dashboard]` در هر برگه‌ای قابل استفاده است. منو در سمت راست قرار دارد و محتوای هر بخش با Ajax بدون رفرش صفحه بارگذاری می‌شود. نمایش فرم‌ها بر پایه Gravity Forms بوده و برای نقش‌های `administrator` و `water-manager` فعال است.

### ویژگی‌ها
- رابط کاربری دو ستونه با طراحی گرافیکی مدرن و راست‌چین.
- پنج منوی اصلی: ثبت قبض، تاریخچه قبض، ثبت مشترک جدید، اطلاعات مشترکین و ارسال اطلاعیه.
- بارگذاری محتوای هر منو با Ajax و بدون رفرش.
- امکان سفارشی‌سازی نقش‌های مجاز و شناسه فرم‌ها از طریق فیلترها.

### استفاده
1. افزونه را در پوشه پلاگین‌های وردپرس قرار دهید و فعال کنید.
2. مطمئن شوید فرم‌های Gravity Forms با شناسه‌های پیش‌فرض (1 تا 5) وجود دارند یا از فیلتر `water_bill_dashboard_views` برای تغییر شناسه‌ها استفاده کنید.
3. شورت‌کد را در برگه یا قالب المنتوری خود قرار دهید:
   ```
   [water_bill_dashboard]
   ```

### فیلترها
- `water_bill_dashboard_allowed_roles`: تغییر نقش‌های مجاز برای مشاهده داشبورد.
- `water_bill_dashboard_views`: تغییر لیبل، آیکن و شناسه فرم هر منو. -->
